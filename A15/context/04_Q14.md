# 研究问题：逆散射中的生成式潜空间究竟应该建立在哪里？

我们已经完成了一轮 Shared Physical Flow / Multi-Decode 的初步数值研究。当前结果没有否定 Flow Matching 在逆问题中的价值，但明确暴露出：**随意选择一个由 material map 压缩得到的 learned latent，再要求它同时支撑 material、current、field、reflectivity 等多个独立 decoder，并不会自然产生一个物理一致的 shared representation。**

上一轮最重要的正面结果是：

\[
\boxed{
\text{Conditional Flow 可以学习 measurement 未约束方向上的 conditional prior/posterior completion。}
}
\]

在线性可控 toy problem 中，measurement 只观测一部分 latent，而另一部分严格处于 null space。Conditional Flow 能够学习这些不可观测方向的多模态条件分布，而 deterministic regression 容易产生 mode averaging。OOD 时 Flow 会按照训练 prior 错误补全，而 measurement residual 仍然可以接近零。这说明：

\[
\boxed{
\text{generative prior completion}
\neq
\text{recovery of information absent from measurements}.
}
\]

这点应视为已经确认的研究边界，而不是需要绕开的缺点。

上一轮最主要的失败出现在真实物理 toy problem。我们使用 2D scalar Helmholtz scattering，在同一 scene 上生成 material contrast \(\chi\)、current \(J\)、total field \(E\)、reflectivity/scattering potential \(\rho\) 和 receiver measurements \(y\)。然后用一个小型 CNN：

\[
\chi\rightarrow z\in\mathbb R^{16\times 8}
\]

生成 learned latent，再让 conditional Flow 学：

\[
y\rightarrow p(z|y),
\]

并让同一 sampled latent 独立 decode：

\[
z\rightarrow\chi,\quad
z\rightarrow J,\quad
z\rightarrow E,\quad
z\rightarrow\rho.
\]

结果这些输出虽然单独具有一定重建能力，但并不属于同一个物理解：

\[
J\neq\chi E,
\]

\[
E\neq E_{\rm inc}+GJ,
\]

\[
F(\chi)\not\approx y
\]

到足够精度。

对 material output 做 data-consistency correction 可以改善 \(F(\chi)-y\)，但反而恶化 \(J-\chi E\)，进一步说明当前 latent 并不是一个 coherent physical state。

此外，多任务 supervision 没有稳定地使 encoder latent 优于 material-only latent；不同 seed 间收益不稳定，held-out material functional 甚至往往更差。增加 sampling steps、self-conditioning、mode ratio 调整和更多训练数据都没有显示足以解释失败的趋势。

因此现在真正的研究问题已经发生变化。

---

# 核心问题

我们不再问：

> Flow Matching 能不能用于 inverse scattering？

也不再问：

> 能不能让一个 Transformer 同时输出很多 physical modalities？

现在真正的问题是：

\[
\boxed{
\textbf{Where should the generative flow live?}
}
\]

也就是：

> 对于欠定、病态、非线性的 electromagnetic inverse problem，什么 representation / basis / manifold / operator coordinates 最适合作为 conditional generative posterior 的 latent space？

进一步：

> 哪些状态自由度应该主要由 measurement 决定，哪些自由度应该主要由 prior 决定？

以及：

> Flow Matching 应该作用于完整 latent，还是只作用于 measurement weak/null directions？

最终希望建立一个具有明确物理意义的结构：

\[
\boxed{
\text{measurement-informed state}
+
\text{prior-informed generative state}
}
\]

而不是让 neural network 同时重新学习两者。

# 一、希望首先解决的理论问题：什么叫“好的 latent”？

请不要预设 latent 必须来自 autoencoder，也不要预设 Gaussian、wavelet、POD、current 或 scattering modes 中任何一种一定正确。

希望从 inverse-problem theory 出发，定义：

\[
z=E(x),\qquad x=D(z)
\]

中的 latent \(z\) 应满足什么性质。

至少需要从以下几个角度探索。

---

## 1. Measurement sufficiency

设真实 forward operator：

\[
y=F(x)+n.
\]

若使用 latent：

\[
x=D(z),
\]

则有效 forward map 为：

\[
F_z(z)=F(D(z)).
\]

希望研究：

\[
J_{F_z}
=
J_FJ_D
\]

应该满足什么条件，才能保证重要 measurement-sensitive directions 没有在 encoding 中丢失。

可以考虑：

- rank preservation；
- dominant singular-value preservation；
- Fisher information preservation；
- Gauss–Newton Hessian preservation；
- mutual information；
- Bayesian sufficiency；
- approximate sufficient statistics；
- information bottleneck；
- active subspace；
- observability Gramian；
- task-aware observability。

重点研究：

\[
\boxed{
\text{低 reconstruction error 是否完全不足以说明一个 latent 适合 inverse inference？}
}
\]

上一轮结果已经提示答案很可能是 yes。

需要给出更严格的理论解释。

---

## 2. Prior sufficiency

一个 inverse latent 不应该只保留 measurement information。

因为我们希望 Flow 能够表示 posterior：

\[
p(x|y).
\]

因此 latent 还需要保留 prior 中与 posterior ambiguity 有关的自由度。

也就是说，一个好的 latent 可能需要同时保留：

\[
\text{data-sensitive directions}
\]

和

\[
\text{prior-variable directions}.
\]

请研究这两者如何统一。

可能的对象包括：

- prior covariance；
- posterior covariance；
- score/Fisher geometry；
- transport geometry；
- manifold tangent space；
- nonlinear intrinsic coordinates。

特别研究：

> 如果某方向 measurement 几乎完全看不见，但它对 downstream task 很重要，应该如何表示并生成？

---

## 3. Task sufficiency

我们未来可能希望从 posterior state 获得很多不同 quantity：

\[
J,\quad E,\quad H,\quad \chi,\quad
\epsilon,\quad\sigma,\quad\mu,
\]

\[
S/T\text{-matrix},
\]

\[
\text{receiver response},
\]

\[
\text{reflectivity},
\]

\[
\text{spectral/color response},
\]

\[
\text{effective impedance/admittance},
\]

\[
\text{equivalent circuit descriptors},
\]

以及未来尚未定义的物理 quantity。

因此 latent 不应只针对 material reconstruction。

请研究 task-aware latent sufficiency。

例如局部情况下：

\[
\ker J_F
\subseteq
\ker J_{D_k}
\]

意味着 measurement-null directions 不影响 task \(k\)。

对于多个 task：

\[
\ker J_F
\subseteq
\bigcap_k
\ker J_{D_k}.
\]

但这个条件可能太强，因为 generative posterior 可以保留 uncertainty。

请进一步发展 probabilistic 版本：

\[
p(z|y)
\rightarrow
p(q_k|y).
\]

希望明确：

- 哪些 task 可以 deterministic recover；
- 哪些只能 probabilistically infer；
- 哪些在给定 measurement 下根本无法受到有效约束；
- 哪些 task 共享同一 uncertainty source；
- 哪些 task 实际包含不同信息。

---

# 二、重点研究 Likelihood-Informed Subspace

Likelihood-Informed Subspace 是当前非常值得重点研究的方向，但请不要因此排除其他方案。

希望从 Bayesian inverse problem 的角度研究 generalized eigenproblem：

\[
H_{\rm GN}v
=
\lambda C_{\rm prior}^{-1}v,
\]

其中：

\[
H_{\rm GN}
=
J_F^\ast\Gamma_n^{-1}J_F.
\]

或者它在 nonlinear/posterior-averaged 情况下的扩展。

直觉上：

\[
\lambda\gg1
\]

对应 measurement-informed directions；

\[
\lambda\ll1
\]

对应 prior-dominated directions。

希望研究是否可以建立：

\[
z=
(z_{\rm data},z_{\rm prior})
\]

并让 inverse solver 和 generative model 分工：

\[
y
\rightarrow
z_{\rm data}
\]

主要由 physics / likelihood 确定；

而：

\[
p(z_{\rm prior}|y,z_{\rm data})
\]

由 Flow Matching 学习。

这可能是整个方向最重要的 reframing：

\[
\boxed{
\textbf{Physics handles information; generative flow handles uncertainty.}
}
\]

请认真推导这个框架是否成立，是否已有经典理论支持，是否存在更好的 formulation。

# 三、不要限制在线性 subspace：研究 nonlinear manifold

我们并不认为真实 inverse solution manifold 必须接近一个线性子空间。

需要研究：

- nonlinear autoencoder；
- variational autoencoder；
- invertible neural representation；
- normalizing-flow representation；
- manifold autoencoder；
- kernel PCA；
- diffusion autoencoder；
- neural operator latent；
- nonlinear reduced-order models；
- chart/atlas based latent manifolds。

特别研究：

> 如果 linear Kolmogorov \(n\)-width 衰减很慢，但 nonlinear manifold dimension 很低，Flow 是否应该直接定义在 nonlinear intrinsic coordinates 上？

但不要简单使用 reconstruction-trained autoencoder。

需要研究怎样让 encoder objective 同时考虑：

\[
\text{reconstruction}
+
\text{measurement sensitivity}
+
\text{task sensitivity}
+
\text{prior geometry}.
\]

是否可以定义：

\[
L_{\rm latent}
=
L_{\rm recon}
+
\lambda_F L_{\rm forward}
+
\lambda_J L_{\rm Jacobian}
+
\lambda_T L_{\rm task}
+
\lambda_P L_{\rm prior}
\]

或更有原则的 variational objective？

也请考虑：

> encoder/decoder 是否应该与 Flow jointly trained？

还是：

> latent 应先由物理/信息几何定义，再冻结训练 Flow？

# 四、系统比较可能的 latent families

请不要只讨论一种。

至少系统研究：

## A. Pixel / raw material space

作为 baseline。

优点：

- 无压缩信息损失；
- data consistency 容易定义。

缺点：

- 维数高；
- posterior geometry 复杂；
- Flow 成本高。

---

## B. Wavelet / multiscale sparse representation

研究：

\[
x=W\alpha.
\]

关注：

- localization；
- multiscale；
- boundary representation；
- sparse prior；
- measurement sensitivity；
- inverse scattering 中已有 wavelet regularization / sparse inversion 文献。

研究不同 wavelet：

- Haar；
- Daubechies；
- biorthogonal；
- complex wavelet；
- wavelet packet；
- learned wavelet。

更进一步：

> 是否应该让 Flow 只生成高频/detail coefficients，而 measurement reconstruction 负责 coarse/visible coefficients？

这可能天然对应：

\[
\text{observable low-frequency structure}
+
\text{prior-completed fine structure}.
\]

但不要假设 inverse scattering 的可见/不可见恰好等同于 frequency scale，需要严格分析。

---

## C. Fourier / spectral basis

研究哪些 spatial-frequency modes 受有限 aperture / finite bandwidth measurement 控制。

逆散射中的 diffraction limit 和 missing cone / missing spatial frequency 是否可以直接形成：

\[
z_{\rm observed-spectrum}
+
z_{\rm missing-spectrum}
\]

的 generative decomposition。

这可能比一般 LIS 更具有 EM 直觉。

需要研究：

- Born regime；
- nonlinear multiple-scattering regime；
- near field / far field；
- multi-frequency；
- limited angle。

---

## D. POD / PCA / Karhunen–Loève

作为经典 prior-optimal linear compression。

研究：

\[
C_x\phi_i
=
\lambda_i\phi_i.
\]

明确：

- 它对 prior variance 最优；
- 但不一定对 likelihood / inverse information 最优。

希望把它作为其他 latent 的重要 baseline。

---

## E. Active Subspace / Hessian eigenbasis

研究：

- Gauss–Newton modes；
- sensitivity SVD；
- Fisher eigenspaces；
- active subspaces；
- generalized eigenvectors against prior covariance。

与 LIS 统一比较。

---

## F. Characteristic Modes

如果适用于当前 scatterer class，重点研究 Harrington/Mautz characteristic modes 及其 dielectric/penetrable-body extensions。

这些 modes 是否能够作为：

\[
\boxed{
\text{excitation-independent scattering coordinates}
}
\]

？

它们相比 material coordinates 的优势是否是：

\[
\text{one state}
\rightarrow
\text{many illuminations / fields / currents}
\]

更自然？

需要研究：

- PEC；
- penetrable dielectric；
- lossy media；
- vector Maxwell；
- integral operator characteristic modes；
- resonant modes；
- non-orthogonal modes；
- frequency dependence。

---

## G. Scattering eigenchannels / S-matrix / T-matrix eigenmodes

研究是否应该把 latent 建立在：

\[
S,\quad T,\quad
\text{scattering eigenchannels}
\]

或者它们的低秩 representation 上。

重点回答：

> 如果最终 downstream quantity 包括 current、field、receiver response、multi-illumination response，那么 scattering operator/state 是否比 material state 更接近真正的 shared physical latent？

同时研究 material information 是否会在 operator compression 中不可逆丢失。

---

## H. Current / contrast-source space

经典 contrast-source inversion 已经说明：

\[
J=\chi E
\]

可以把 inverse scattering 写成 current/material coupled problem。

研究：

- current 是否更接近 measurement；
- current 是否 illumination-dependent；
- 单 illumination current 是否无法作为 universal object state；
- multi-illumination current bank 是否更好；
- current subspace 是否可以通过 SVD / characteristic modes 压缩。

---

## I. Learned latent

研究如何避免上一轮：

\[
\chi\rightarrow \text{CNN code}
\]

这种“只针对 reconstruction 压缩”的问题。

考虑：

- physics-informed autoencoder；
- measurement-aware autoencoder；
- task-aware autoencoder；
- contrastive multimodal latent；
- canonical correlation / deep CCA；
- multimodal autoencoder；
- operator-aware latent。

---

## J. Hybrid latent

重点允许提出混合方案。

例如：

\[
z=
[
z_{\rm LIS},
z_{\rm wavelet-residual}
]
\]

或：

\[
z=
[
z_{\rm scattering-mode},
z_{\rm prior-detail}
]
\]

甚至：

\[
z=
[
z_{\rm observable},
z_{\rm weak},
z_{\rm null}
].
\]

其中不同部分使用不同 inference mechanism。

不要追求“一种 basis 统治所有问题”。

# 五、特别研究 observable / weak / null 三分，而不只是二分

真实 nonlinear inverse problem 并不只有：

\[
\text{observable}
\]

和：

\[
\text{null}.
\]

更重要的是大量 weak directions。

希望建立：

\[
\mathcal Z
=
\mathcal Z_{\rm strong}
\oplus
\mathcal Z_{\rm weak}
\oplus
\mathcal Z_{\rm null}.
\]

其中：

### strong

measurement strongly constrains；

### weak

measurement 提供部分信息，但 prior 仍很重要；

### null

measurement 基本不约束。

然后研究不同 inference strategy：

\[
z_{\rm strong}
\]

用 deterministic / Gauss–Newton / adjoint inversion；

\[
z_{\rm weak}
\]

用 conditional generative correction；

\[
z_{\rm null}
\]

主要由 posterior prior sampling。

这可能比简单：

\[
\text{deterministic + Flow}
\]

更真实。

希望探索：

- smooth weighting；
- continuous eigenvalue threshold；
- anisotropic noise schedule；
- subspace-dependent diffusion/flow；
- likelihood-guided vector field；
- preconditioned Flow Matching。

# 六、Flow Matching 应该如何利用物理信息？

不要预设 Flow 只是：

\[
p(z|y)
\]

的 black-box conditional generator。

研究至少以下可能性。

---

## 1. Posterior Flow only

直接学习：

\[
p(z|y).
\]

作为 baseline。

---

## 2. Prior Flow + explicit likelihood guidance

先学习：

\[
p(z),
\]

然后 inference 时用：

\[
\nabla_z
\log p(y|D(z))
\]

guidance。

分析：

\[
\nabla_z
=
J_D^\ast J_F^\ast
\Gamma_n^{-1}
(y-F(D(z))).
\]

这直接暴露 decoder Jacobian rank-loss 问题。

---

## 3. Likelihood-informed conditional Flow

在 vector field 中显式加入 forward operator / residual。

---

## 4. Flow only on prior-dominated coordinates

这是重点候选方案。

---

## 5. Full-space physical correction + latent projection

如果 latent decoder Jacobian 丢失 measurement-sensitive directions：

\[
J_D
\]

rank deficient，

那么 data consistency 是否应该在 physical/full space 做：

\[
x\leftarrow
x-\eta\nabla_xL_{\rm data},
\]

再重新 encode：

\[
z\leftarrow E(x)?
\]

研究这种 alternating scheme。

---

## 6. Constrained/manifold Flow

如果 latent 本身受：

- passivity；
- reciprocity；
- positivity；
- causality；
- geometry；
- energy conservation；

等约束，是否需要：

- Riemannian Flow Matching；
- manifold CFM；
- projected flow；
- constrained transport；
- intrinsic coordinates。

# 七、重新思考 multi-decode

上一轮已经说明：

\[
z\rightarrow
\chi,J,E,\rho
\]

四个 independent neural heads 并不会自动产生物理一致性。

所以这次请从零重新研究 multi-decode 的含义。

---

## 1. Decoder hierarchy

不要把所有 quantity 当平级 heads。

研究可能的 hierarchy：

\[
\text{canonical state}
\rightarrow
\text{current}
\rightarrow
E/H
\rightarrow
\text{measurements}.
\]

或者：

\[
\text{scattering operator}
\rightarrow
\begin{cases}
J_s\\
E_s/H_s\\
S/T\\
y_s
\end{cases}
\]

而 material 可能是：

\[
p(\chi|\text{scattering state}).
\]

明确哪些 mapping：

- EXACT ANALYTIC；
- NUMERICAL PHYSICS；
- LEARNED DETERMINISTIC；
- PROBABILISTIC；
- NOT IDENTIFIABLE。

---

## 2. 一个 shared latent 是否真的应该 decode material？

这是一个开放问题。

如果：

\[
\text{many materials}
\rightarrow
\text{same scattering state},
\]

那么 material decoder 本质上应该：

\[
p(\chi|z),
\]

而不是 deterministic：

\[
\chi=D(z).
\]

这反而可能形成第二层 generative decoding。

请大胆探索：

\[
y
\rightarrow
p(z_{\rm scat}|y)
\rightarrow
p(\chi|z_{\rm scat}).
\]

---

## 3. Current / E / H 是否应该 neural decode？

如果给定 canonical physical state 后 Maxwell solver 可以廉价得到：

\[
J,E,H,
\]

那么 neural decoder 也许毫无必要。

不要为了保持“multi-decode”概念而强行使用神经 head。

真正的目标是：

\[
\boxed{
\text{multiple physically meaningful readouts}
}
\]

而不是：

\[
\text{multiple neural decoders}.
\]

# 三十一、不要过度谨慎

本次理论研究的目标不是马上给出一篇完全证明 global Maxwell theorem 的论文。

不要因为：

- 只能证明局部；
- 只能在线性化下推导；
- nonlinear case 没有 closed form；
- 3D vector Maxwell 暂时没有实验；
- 某个结论需要 regularity assumptions；

就不断把研究问题缩小到失去意义。

应采用：

\[
\boxed{
\text{大胆提出强机制}
\rightarrow
\text{明确成立条件}
\rightarrow
\text{主动找反例/边界}
}
\]

而不是：

\[
\text{因为无法证明所有情况}
\rightarrow
\text{什么也不敢说}.
\]

如果 controlled regime 里存在非常强的 mechanism，请把它发展到最大，再说明 regime。

同时也不要为了支持已有想法而强行正面。

如果某条路线实质上没有 novelty，或者存在 fundamental obstruction，应明确杀掉。
