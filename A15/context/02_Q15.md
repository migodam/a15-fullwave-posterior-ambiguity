A14 已完成，但没有进入 Flow training，实验数据和报告在[https://github.com/migodam/a14-task-relevant-posterior-coordinates](https://github.com/migodam/a14-task-relevant-posterior-coordinates)。当前结果是：

- 离散 full-wave material-current tangent 实现可靠；
- measurement information spectrum 与 task residual uncertainty spectrum 在局部 Gaussian/tangent 意义上明显不同；
- task-aware generalized eigenvectors 比 POD/LIS/random 更能找到 measurement-weak / task-sensitive directions；
- 但是 finite-amplitude effect 的绝对量和跨场景 prevalence 不足；
- 当前主设置 internal-current witness 为 4/32、4/32、1/32，新 receiver task 为 0/96；
- 更重要的是，在原 Gaussian-blob generator 的合法连续参数支持内，只有 1/96 scene 出现刚过阈值的 internal-current witness；
- 因此 Gate A 只有 PARTIAL PASS，Gate B、reference posterior 和 Flow 均未运行。

现在不要优先研究“如何把 Flow 调好”，而请研究下面的问题。

1. **为什么当前大量 Flow Matching inverse-problem / inverse-design 工作可以取得正面结果，而本问题在 Flow 之前就遇到 representation/mechanism gate？**

   重点比较：
   - Null-Space Flow Matching for MIMO；
   - Fast and Faithful conditional FM；
   - EngiOpt conditional FM；
   - physics-constrained FM；
   - EM/metasurface inverse-design FM；
   - IrisFlow；
   - latent Flow inverse solvers，例如 HDPS。
   对每项明确说明：
   - Flow 实际运行在哪个空间；
   - 该空间是 full physical state、physical parameter space、Fourier/angular coordinates、learned latent 还是其他；
   - 是否存在 encoder/decoder；
   - measurement consistency 如何实现；
   - 它评价的是 posterior calibration、reconstruction、candidate design quality 还是 optimization warm-start；
   - 它取得正面结果的任务是否本质上比我们的 task-aware posterior inference 更容易。
2. **重新研究“Flow 应该住在哪里”这个问题，但不要预设 LIS、Wavelet、autoencoder 或 material space 一定正确。**

   特别比较：

   - Fourier/spectral coordinates；
   - LIS / prior-preconditioned sensitivity coordinates；
   - task-aware generalized coordinates；
   - characteristic/current/scattering modes；
   - operator state；
   - learned nonlinear latent；
   - stochastic latent with residual/fiber variables。
3. **重点研究真实 prior manifold，而不是 Gaussian covariance surrogate。**

   当前 A14 使用 (C\_0^{1/2}v) 定义局部 directions，但很多 affine directions 不属于原 blob generator support。

   考虑直接以 generator parameters

   [\
   \theta=(a\_i,x\_i,y\_i,w\_i,r\_i,\phi\_i,\ldots)\
   ]

   为坐标，构造

   [\
   J\_{F,\theta},\qquad J\_{Q,\theta},\
   ]

   并直接在真实 generator tangent manifold 上定义 measurement-information 与 task-residual spectra。

   研究：
   - 这种 parameter-manifold formulation 是否比 ambient material covariance 更正确；
   - variable number of atoms、permutation symmetry、parameter degeneracy 如何处理；
   - 是否需要 quotient manifold / set-equivariant coordinates；
   - 如何从 local parameter tangent 扩展到 finite prior-supported branches。
4. **研究 latent sufficiency 的概率版本。**

   不要假定好的 latent 必须允许 deterministic reconstruction

   [\
   X=D(Z).\
   ]

   研究是否更合理的是：

   [\
   X=D(Z,\Xi),\
   ]

   即 latent 只保留 likelihood/task-relevant coordinates，而 compression fiber 中剩余的不确定性通过额外随机变量保留。

   希望给出 measurement sufficiency、task sufficiency 和 posterior sufficiency 的数学条件，例如条件独立、条件互信息、forward distortion、Jacobian/Fisher preservation 等。
5. **研究 local spectrum 与 global posterior ambiguity 的关系。**

   当前真正的理论缺口是：

   [\
   J\_F,J\_Q\
   ]

   中存在 measurement-weak/task-strong tangent direction，

   并不意味着真实 non-Gaussian prior 中有显著 posterior mass 沿该方向变化。

   请研究哪些附加条件可以把局部 tangent mismatch 推向：
   - finite-amplitude level set；
   - prior-supported object pair；
   - posterior branch；
   - non-negligible posterior task variance。
   需要寻找可检验 sufficient conditions，而不仅是一个 generalized eigenproblem。
6. **重新研究什么 downstream task 最容易产生真正有意义的 hidden uncertainty。**

   当前 shifted-receiver task 几乎完全失败。

   系统比较：
   - internal current；
   - current hotspot；
   - absorbed power/heating；
   - local field enhancement；
   - new illumination；
   - new frequency；
   - new polarization；
   - near-field task vs far-field acquisition；
   - limited aperture；
   - resonance / near-contact multiple scattering。
   目标是判断哪些 task 与当前 measurement 的 observable current subspace 真正不同。
7. **研究 A14 中 multiple-scattering 线索。**

   Born-to-full discrepancy 与 task effect 有弱到中等的正相关线索，但当前证据不足。

   从 material-current transfer

   [\

   - weak/strong transfer singular values；
