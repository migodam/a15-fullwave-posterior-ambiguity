# 结论：保留生成式后验，但必须重构“生成在哪里”和“生成什么”

**我的总体判断是：旧架构不值得继续靠调参挽救；新的研究方向值得继续，但应当是 `GO WITH MAJOR REFRAMING`，而不是直接给“LIS + Flow”贴上强原创性标签。**

更准确地说：

| Formulation | 判断 |
|---|---|
| 任意 material autoencoder latent，加上彼此独立的 \(\chi,J,E,\rho\) heads | **NO-GO，作为主架构应停止** |
| “物理恢复可见部分，Flow 只生成 null-space 部分”作为主要创新 | **NO-GO，已有非常直接的近邻** |
| **利用全波材料—电流传递机制，区分测量信息与任务相关不确定性，并生成属于同一个物理解的联合后验样本** | **GO WITH MAJOR REFRAMING，值得作为新主线** |

这里有一个会实质影响论文定位的文献发现：**2026 年已经出现了 NullFlow，以及用于 MIMO 信道估计的 Null-Space Flow Matching。**前者直接把生成流限制在测量一致的子空间，后者明确分离 observation-informed 和 underdetermined components。因此，“只在 null space 生成”不能再作为你这条路线的核心原创点。:chatgpt-content-reference{index="0"}

我认为你真正应该追的问题是：

\[
\boxed{
\begin{aligned}
&\text{哪些材料自由度改变测量？}\\
&\text{哪些剩余自由度仍然改变电流、内部场或新照明响应？}\\
&\text{如何保留这些自由度的正确联合概率，而不是把它们删掉或独立补全？}
\end{aligned}}
\]

这比“选择一个更好的 autoencoder”更有理论内容，也更容易与电磁机制建立不可替代的联系。

下面把理论、架构、文献定位和下一轮实验连起来说明。你附件中的实验现象按已有报告处理；本轮另外做了几个解析和一维数值积分核验，**没有把它们冒充成新的 Maxwell 实验**。

# 一、上一轮究竟为什么失败？

## 1. 最确定的问题，是输出没有属于同一个物理解

附件报告的主要现象是：独立 heads 输出的材料、电流和场不满足共同的本构与传播关系；只修正材料的 data consistency，还可能进一步恶化其他输出之间的关系。这个证据直接指向的是**联合状态构造方式失败**。:chatgpt-content-reference{index="1"}

但是，需要把两句话区分开：

> “当前 encoder–Flow–decoder 整体没有产生 coherent physical state。”

这是已有结果支持的。

> “这个 latent 本身不可能包含 coherent physical state 所需的信息。”

**这还没有被证明。**也可能是 decoder 没有正确利用已有信息，或者训练目标把不同物理量推向了不同的条件均值。

### 一个非常直接的反例：完美的均方误差 heads，也可能不满足物理

假设一个 latent \(z\) 无法区分两个等概率状态：

\[
(\chi,E,J)=(1,1,1),\qquad (2,2,4).
\]

两个状态都满足

\[
J=\chi E,
\qquad
E=\frac23+\frac13J.
\]

独立均方误差训练的最优 heads 会给出：

\[
\widehat\chi=1.5,\qquad
\widehat E=1.5,\qquad
\widehat J=2.5.
\]

但

\[
\widehat\chi\,\widehat E=2.25\neq 2.5=\widehat J.
\]

问题并不是某个 head 没训练好，而是：

\[
\boxed{
\mathbb E[\chi E\mid z]
\neq
\mathbb E[\chi\mid z]\mathbb E[E\mid z].
}
\]

差值正是条件相关性造成的。

**所以，多任务预测正确的边缘均值，不等于生成正确的联合物理 realization。**

这也是为什么“给每个 head 多加一点 supervision”不一定解决问题。

## 2. 失败原因的主次应这样排序

| 问题 | 当前判断 |
|---|---|
| 独立 heads 没有共同的物理状态约束 | **证据最直接，首要问题** |
| 压缩 latent 丢失测量敏感或任务相关自由度 | **高度可疑，但需要 oracle reconstruction、Jacobian 和随机补全测试才能确认** |
| posterior ambiguity 被均值预测或确定性 decoder 消掉 | **理论上明确存在的风险** |
| Flow 本身无法学习目标分布 | **现有证据不足以认定它是主要原因** |
| 数据不足、训练不足、过拟合 | **没有被排除，但不应继续当作默认解释** |
| 逆问题不可辨识 | **解释“为什么答案不唯一”，不解释“为什么单个样本违反物理方程”** |

尤其不能把“增加了一些数据没有明显改善”升级成“数据问题已经排除”。2026 年关于有限训练数据的 physics-constrained conditional flow 工作，专门讨论了过训练导致的方差塌缩和样本记忆问题。:chatgpt-content-reference{index="2"}

**因此，下一轮应该先拆开 representation error、decoder coupling error 和 posterior-learning error，而不是继续把三者混在同一个 end-to-end loss 里。**

# 二、什么才叫一个适合逆问题的 latent？

这里最重要的修正是：

\[
\boxed{
\text{好的 inverse latent，不一定对应一个确定性 decoder。}
}
\]

它完全可能对应：

\[
x=D(z,\xi),
\]

其中 \(z\) 保留需要学习或更新的坐标，\(\xi\) 保留压缩后仍然存在的条件不确定性。

## 1. 一套统一的数学定义

固定测量设计，设

\[
X\sim p_0(x),\qquad Y=F(X)+N,
\]

并设我们关心的物理量为

\[
Q_k=Q_k(X).
\]

这里 \(X\) 是 canonical physical state，可以是材料参数、几何与本构参数的组合。以下线性代数公式先使用实坐标；复数测量可按实部、虚部展开，并使用相应噪声协方差。

定义一个固定 encoder：

\[
Z=e(X).
\]

同时定义压缩纤维上的条件先验：

\[
K_0(dx\mid z)=p_0(dx\mid Z=z).
\]

所谓“纤维”，就是所有编码成同一个 \(z\) 的物理状态：

\[
\{x:e(x)=z\}.
\]

### Measurement sufficiency 的正确条件

若

\[
Y\perp X\mid Z,
\]

即给定 \(Z\) 后，\(X\) 的其余细节不再影响测量概率，那么

\[
\boxed{
p(dx\mid y)
=
\int K_0(dx\mid z)\,p(dz\mid y).
}
\]

这给出了精确的分工：

\[
\boxed{
\text{学习低维 posterior update}
+
\text{保留条件先验中的剩余随机性}.
}
\]

在固定协方差的加性高斯噪声模型中，一个充分条件是

\[
F(x)=f(e(x))
\]

在先验支持上成立。

**注意：这并不要求 \(x\) 可以由 \(z\) 唯一重建。**

这也是经典 likelihood-informed reduction 的核心区别：它降低的首先是**似然更新所依赖的维数**，不是把整个后验分布的支持压到一个低维平面上。:chatgpt-content-reference{index="3"}

## 2. 一个能把“latent 选错”和“Flow 没学好”分开的恒等式

假设生成器学习 \(q_\phi(z\mid y)\)，并使用正确的条件先验提升回物理空间：

\[
q_\phi(dx\mid y)
=
\int K_0(dx\mid z)q_\phi(dz\mid y).
\]

由 KL 散度链式法则，在相关条件分布存在且散度有定义时，有：

\[
\boxed{
\mathbb E_Y
D_{\mathrm{KL}}
\bigl(p(X\mid Y)\,\|\,q_\phi(X\mid Y)\bigr)
=
I(X;Y\mid Z)
+
\mathbb E_Y
D_{\mathrm{KL}}
\bigl(p(Z\mid Y)\,\|\,q_\phi(Z\mid Y)\bigr).
}
\]

它把误差分成了两类：

\[
\underbrace{I(X;Y\mid Z)}_{\text{编码后丢失的测量相关信息}}
+
\underbrace{\text{latent posterior 学习误差}}_{\text{Flow 或其他推断器的问题}}.
\]

推导很直接：先按 \(Z\) 分解物理空间后验，再对 \(Y\) 平均；条件后验 \(p(X\mid Z,Y)\) 与条件先验 \(p_0(X\mid Z)\) 之间的平均 KL，就是条件互信息。

这个恒等式不是在宣称一条新的信息论定理，而是在告诉你：

> **再强的 Flow，也不能补偿已经被 encoder 丢掉的测量相关信息；但 encoder 不需要保留所有细节为确定性坐标，只要没有删除相应的条件随机性。**

如果实际使用的 stochastic decoder 也不准确，还需要再计入条件提升核的误差。

## 3. 为什么低 reconstruction error 不够？

考虑

\[
X=(U,\varepsilon V),
\qquad U,V\sim\mathcal N(0,1),
\]

而测量为

\[
Y=\frac{X_2}{\varepsilon}+N=V+N.
\]

丢掉第二个坐标只造成

\[
\mathbb E\|X-\widehat X\|^2=\varepsilon^2,
\]

可以任意小。

但被删掉的恰恰是**全部测量相关信息**。

所以应当比较的不是单纯的材料像素误差，而是噪声归一化后的 forward distortion，例如

\[
\mathbb E\left[
\left\|
\Gamma_n^{-1/2}
\left(F(X)-F(D(e(X)))\right)
\right\|^2
\right].
\]

这里还要避免另一种过度表述：**不是所有 forward-value accuracy 都不够。**

若完整物理先验被保留，只是用 \(\widetilde F\) 替换 forward operator，在相同加性高斯噪声下，由联合分布的 KL 链式分解可得：

\[
\boxed{
\mathbb E_{Y\sim p_Y}
D_{\mathrm{KL}}
\bigl(p(X\mid Y)\,\|\,\widetilde p(X\mid Y)\bigr)
\le
\frac12
\mathbb E_{X\sim p_0}
\left\|
\Gamma_n^{-1/2}(F(X)-\widetilde F(X))
\right\|^2.
}
\]

因此：

**先验分布范围内、噪声尺度归一化的 forward accuracy，确实可以控制平均后验误差。**

它不同于“某个重建点的 residual 很小”，也不同于“某几幅场图看起来很接近”。

Jacobian accuracy 的额外意义，在于保证局部信息几何、优化更新、子空间选择和高效采样器的正确性；不能把它说成所有后验一致性的唯一必要条件。导数感知 surrogate 与 Bayesian sampling 的结合已有成熟研究。:chatgpt-content-reference{index="4"}

## 4. Task sufficiency 应分成确定性和概率性两层

对同一个参数切空间，局部确定性条件是

\[
\ker J_F\subseteq\ker J_Q.
\]

这意味着所有测量不可见的微扰，也不影响任务。

在有限维下，它等价于存在一个线性映射，使

\[
J_Q=KJ_F.
\]

但即使这个条件成立，若

\[
\|J_QJ_F^\dagger\|
\]

很大，任务仍然可能对噪声极敏感。

概率版本更自然：

\[
p(X\mid y)\longrightarrow p(Q_1,\ldots,Q_K\mid y).
\]

这里必须保留的是**联合分布**，不只是每个任务单独的均值、方差或 coverage。

还有一个根本限制：

> 如果真实后验在 \(d\) 维空间具有密度，那么一个低于 \(d\) 维、光滑的确定性 decoder，一般不能精确表示这个完整后验。

要么先验本来就位于低维流形上，要么需要额外随机坐标，要么明确承认目标只是某些任务的近似后验。

# 三、LIS 应该成为核心，但不能被理解成“strong 确定、null 随便生成”

## 1. 在线性高斯模型中，分工可以完全算清楚

令

\[
X=m_0+C_0^{1/2}U,\qquad U\sim\mathcal N(0,I),
\]

并对白化后的线性模型写成

\[
d=AU+\epsilon,
\qquad
A=\Gamma_n^{-1/2}MC_0^{1/2},
\qquad
\epsilon\sim\mathcal N(0,I).
\]

其中 \(M\) 是线性 forward operator。

设

\[
A=U_A\operatorname{diag}(\sqrt{\lambda_i})V^\top.
\]

在右奇异坐标 \(z_i=v_i^\top U\) 中：

\[
\boxed{
z_i\mid y
\sim
\mathcal N\left(
\frac{\sqrt{\lambda_i}}{1+\lambda_i}\eta_i,
\frac{1}{1+\lambda_i}
\right).
}
\]

其中 \(\eta_i\) 是白化测量在对应左奇异方向上的分量。这正是 prior-preconditioned Hessian/LIS 的标准解释。:chatgpt-content-reference{index="5"}

它给出三种量：

\[
\text{后验方差比例}=\frac1{1+\lambda_i},
\]

\[
\text{方差压缩比例}=\frac{\lambda_i}{1+\lambda_i},
\]

\[
\text{平均信息增益}=\frac12\log(1+\lambda_i).
\]

因此 strong、weak、null 应当按照**数据相对于先验和噪声的作用强弱**定义，而不是根据未经归一化的 Jacobian 奇异值定义。

## 2. Strong 不是没有随机性

即使

\[
\lambda_i=100,
\]

后验方差仍是

\[
\frac1{101}\approx0.0099,
\]

而不是零。

所以

\[
z_{\rm strong}=\widehat z_{\rm strong}(y)
\]

只能是一个需要检验误差的近似，不能直接成为“正确 posterior sampler”的定义。

尤其当任务对这个方向非常敏感时，1% 的参数方差也可能不能忽略。

比较合理的分工是：

\[
\boxed{
\begin{aligned}
z_{\rm strong}&:\text{低维条件采样，或经过校验的局部 Gaussian/Laplace；}\\
z_{\rm weak}&:\text{likelihood 与 prior 共同作用，适合 conditional Flow；}\\
z_{\rm null}&:\text{条件先验采样，简单时根本不需要 Flow。}
\end{aligned}}
\]

此外，局部很 strong 不代表全局单峰。例如 \(F(x)=x^2\) 在两个非零解附近都可能很敏感，但正负分支仍不可由该测量区分。

**全局 branch uncertainty 不能被一张局部 Hessian 吃掉。**

## 3. Null 分量通常不能从独立 marginal prior 生成

正确的精确分解，在似然完全不依赖 \(z_n\) 时是：

\[
\boxed{
p(z_s,z_w,z_n\mid y)
=
p(z_s,z_w\mid y)\,
p_0(z_n\mid z_s,z_w).
}
\]

不是

\[
p(z_s,z_w\mid y)p_0(z_n).
\]

只有在相应坐标下，先验确实独立时，后者才成立。

一个简单核验：设

\[
\begin{pmatrix}X_1\\X_2\end{pmatrix}
\sim
\mathcal N\left(
0,
\begin{pmatrix}
1&0.9\\
0.9&1
\end{pmatrix}
\right),
\]

测量

\[
Y=X_1+N,\qquad N\sim\mathcal N(0,0.1^2),
\]

观测到 \(y=1\)。

虽然测量函数不直接依赖 \(X_2\)，但

\[
\mathbb E[X_2\mid y]\approx0.8911,
\qquad
\operatorname{Var}(X_2\mid y)\approx0.1980.
\]

如果独立地生成

\[
X_2\sim\mathcal N(0,1),
\]

就同时错了均值、方差以及与 \(X_1\) 的相关性。

这里所谓“数据改变了 null 分量”，并没有产生新的物理信息；它是通过先验相关性传递条件信息。

对于非高斯先验，**协方差白化也不意味着独立化**。

## 4. 非线性 LIS 有经典理论支持，但要用对矩阵

Certified dimension reduction 的经典结果，使用的是后验平均的 log-likelihood score 二阶矩：

\[
H_{\rm score}
=
\mathbb E_{X\mid y}
\left[
\nabla\log L_y(X)\,
\nabla\log L_y(X)^\top
\right].
\]

在标准高斯先验坐标下，对应的条件期望似然近似可获得形如

\[
D_{\mathrm{KL}}(p\|p_r)
\le
\frac12\sum_{i>r}\nu_i
\]

的界，其中 \(\nu_i\) 是相应 score 矩阵特征值。更一般的先验需要相应的 subspace log-Sobolev 条件与常数。:chatgpt-content-reference{index="6"}

**不能把这里的 \(H_{\rm score}\)，直接换成任意一个 MAP 点上的 \(J_F^\top\Gamma_n^{-1}J_F\)，然后沿用同一个定理。**

实际算法可以先用便宜的局部 GN/LIS，但论文中应区分：

- 局部几何近似；
- posterior-averaged reduction；
- 有严格分布误差界的 reduction。

为了 amortization，也可以考虑先验平均、data-free LIS，而不是每次观测都先求一个昂贵的完整后验。这个方向同样已有经典工作。:chatgpt-content-reference{index="7"}

# 四、真正值得发展的核心：测量信息谱，与任务剩余不确定性谱，不是同一个谱

这是我认为最有希望把你的电磁机制研究与生成式后验研究连起来的地方。

## 1. 先把材料到电流的传递写清楚

从附件使用的离散对比源关系出发：

\[
J_s=D_\chi E_s,
\qquad
E_s=E_{{\rm inc},s}+GJ_s.
\]

这里：

- \(s\)：照明编号；
- \(D_\chi\)：材料对比度形成的对角算子；
- \(G\)：域内传播算子；
- \(J_s\)：对比源电流；
- \(S_s\)：从电流到当前接收阵列的观测算子。

对材料扰动求导：

\[
(I-D_\chi G)\delta J_s
=
D_{E_s}\delta\chi.
\]

于是定义材料—电流 tangent transfer：

\[
\boxed{
\mathcal T_s
=
(I-D_\chi G)^{-1}D_{E_s}.
}
\]

得到：

\[
\delta J_s=\mathcal T_s\delta\chi,
\qquad
\delta y_s=S_s\mathcal T_s\delta\chi.
\]

因此，材料扰动的作用路径是：

\[
\boxed{
\delta\chi
\rightarrow
\underbrace{D_{E_s}\delta\chi}_{\text{局部场激发}}
\rightarrow
\underbrace{(I-D_\chi G)^{-1}}_{\text{全波内部传递}}
\rightarrow
\underbrace{S_s}_{\text{接收阵列筛选}}.
}
\]

这个分解直接说明：

> 一个方向可以对当前接收数据很弱，却对内部电流、局部场或另一种照明下的响应很强。

它不是“所有 weak directions 都应该由一个黑盒 prior 随便填上”的问题。

## 2. 测量需要一个谱，生成分辨率还需要另一个谱

把材料先验白化，定义

\[
A
=
\Gamma_n^{-1/2}
\begin{bmatrix}
S_1\mathcal T_1\\
\vdots\\
S_m\mathcal T_m
\end{bmatrix}
C_0^{1/2}.
\]

对某个任务 \(Q\)，定义

\[
B_Q=J_QC_0^{1/2}.
\]

例如：

\[
B_{\rm current}
=
\mathcal T_sC_0^{1/2},
\]

而新照明、新接收条件下的预测任务为

\[
B_{\rm new}
=
S_{\rm new}\mathcal T_{\rm new}C_0^{1/2}.
\]

在线性高斯模型，或经过声明的局部 Gaussian 近似中：

\[
\Sigma_U=(I+A^\top A)^{-1}.
\]

任务的后验协方差为

\[
\boxed{
\Sigma_Q
=
B_Q(I+A^\top A)^{-1}B_Q^\top.
}
\]

现在看清楚两个不同对象：

\[
\boxed{
A^\top A
\quad\text{衡量数据在哪些方向压缩先验。}
}
\]

\[
\boxed{
\mathcal U_Q
=
\Sigma_U^{1/2}B_Q^\top W_QB_Q\Sigma_U^{1/2}
\quad\text{衡量哪些剩余随机方向最影响任务。}
}
\]

其中 \(W_Q\) 是任务误差的单位归一化或重要性权重。

**LIS 负责找“后验在哪里偏离先验”。  
\(\mathcal U_Q\) 负责找“剩下的不确定性在哪里仍然重要”。**

这两个问题不能互相替代。Goal-oriented Bayesian reduction 已经建立了结合先验、似然与任务的理论，因此这个总体思想不是空白；你的机会在于把它具体落实为全波材料—电流传递机制和可验证的物理失配。:chatgpt-content-reference{index="8"}

## 3. 一个可以直接使用的任务歧义特征问题

考虑局部 posterior ellipsoid：

\[
\delta u^\top(I+A^\top A)\delta u\le1.
\]

在这个允许范围内，最大的任务变化满足：

\[
\boxed{
\max_{\delta u^\top(I+A^\top A)\delta u\le1}
\|W_Q^{1/2}B_Q\delta u\|^2
=
\lambda_{\max}(\mathcal U_Q).
}
\]

相应方向可通过广义特征问题寻找：

\[
\boxed{
B_Q^\top W_QB_Qv
=
\eta(I+A^\top A)v.
}
\]

它回答的不是“哪种材料变化最容易被测到”，而是：

> **在仍然符合当前数据与先验的变化中，哪一种最可能改变我们关心的物理任务？**

这比“按 LIS 奇异值截断，剩下全部当作不重要”更适合你的问题。

### 一个两维反例

设

\[
A=
\begin{pmatrix}
10&0\\
0&0.1
\end{pmatrix},
\qquad
Q(u)=u_2.
\]

最高 LIS 方向是 \(u_1\)，但它对任务完全没有贡献。

任务方差为

\[
\operatorname{Var}(Q\mid y)=\frac1{1+0.1^2}\approx0.9901.
\]

如果只保留最强 LIS 方向作为 latent，就几乎删除了这个任务的全部后验不确定性。

所以：

\[
\boxed{
\text{低维 likelihood update}
\not\Rightarrow
\text{低维 task uncertainty}.
}
\]

## 4. 这个机制还可以得到不局限于一阶误差的局部结论

设有限维材料参数位于物理可行域内部，Maxwell 离散 forward map \(F\) 和任务 \(Q\) 在附近光滑，且 \(J_F\) 的秩在邻域内恒定。

如果存在

\[
v\in\ker J_F(x_0),
\qquad
J_Q(x_0)v\neq0,
\]

那么由常秩定理，可以找到一条局部曲线 \(x(t)\)，满足

\[
F(x(t))=F(x_0),
\]

同时

\[
Q(x(t))
=
Q(x_0)+tJ_Q(x_0)v+o(t).
\]

也就是说：

\[
\boxed{
\text{存在测量完全相同、但任务不同的真实局部物理状态族。}
}
\]

这不是仅仅说“Fisher 指标小”；在上述正则性条件下，它确实对应测量等值集上的任务变化。

数学工具本身是经典的。**值得研究的是：在什么电磁条件下，这些方向由内部电流传递、照明结构或接收模式筛选产生，以及怎样用少量 probes 找到它们。**

这才有机会形成一篇 mechanism-driven 的电磁论文。

# 五、Canonical physical state：当前首选材料/本构状态，不是单个 current，也不是默认的 T-matrix

## 1. 不应因为上一轮失败，就否定 material 作为 canonical state

给定材料、几何、频率和照明，场与电流由物理模型确定。

因此，材料状态本来就可以是 shared physical state。上一轮的问题是：

\[
\text{压缩材料 code}
+
\text{独立预测其他物理量},
\]

不是“材料无法支撑多个物理 readouts”。

对于当前目标——既关心材料，也关心内部电流、场和新照明响应——我更推荐：

\[
\boxed{
X=(\text{geometry},\text{constitutive parameters})
}
\]

作为 canonical state。

在当前标量单频实验中，它可以退化为 \(\chi\)；未来再扩展到 \(\epsilon,\sigma,\mu\)、张量或色散参数。

## 2. Current 为什么不天然是 universal object state？

单照明电流

\[
J_s
\]

依赖照明 \(s\)。它更接近测量，但不能自动生成任意新照明下的响应。

多照明 current bank 更好，但它只直接覆盖已有入射场张成的空间。

更接近 illumination-independent object response 的对象是：

\[
\boxed{
\mathcal K_\chi
=
(I-D_\chi G)^{-1}D_\chi,
}
\]

使得

\[
J_s=\mathcal K_\chi E_{{\rm inc},s}.
\]

这是“入射场到内部电流”的算子，而不是某次照明下的电流向量。

但是，学习一个完整 \(\mathcal K_\chi\)，可能比学习材料本身更大、更冗余。

## 3. 外部 \(T\)-matrix 不等于完整内部响应算子

在选定的入射、出射波通道下，可以写成

\[
T_\chi
=
R_{\rm out}\mathcal K_\chi R_{\rm in}.
\]

有限通道、截断后的 \(T_\chi\) 很适合外部响应任务，但通常没有理由假定它保留所有内部场或材料信息。

因此，这条路线应当写成：

\[
y\rightarrow p(T\mid y)
\rightarrow p(X\mid T),
\]

而不是默认

\[
T\rightarrow X
\]

有唯一确定性逆映射。

这里也不能反过来说“完整散射算子永远不能确定材料”。唯一性取决于对象类别、频率、边界条件和完整数据条件。**当前真正危险的是把有限、低秩、截断的外部算子当成对所有任务都充分的 object state。**

# 六、十类 latent 的系统判断

下面的排序是针对你现在的研究目标，而不是宣称存在一种通用最优 basis。

| Latent family | 真正的价值 | 主要风险 | 当前建议 |
|---|---|---|---|
| **Raw material / pixel** | 不主动丢弃材料自由度，物理 readout 定义直接 | 高维、先验与后验几何复杂 | 必须保留的基线 |
| **Wavelet / multiscale** | 局部性、尺度结构、边界与稀疏先验方便 | 尺度不等于可观测性；截断可能删掉关键方向 | **优先候选的坐标系统** |
| **Fourier / spectral** | Born 条件下有直接测量频谱解释 | 非线性多次散射下，频率掩膜不再等于完整可见性结构 | 机制基线和特定 regime 候选 |
| **POD / PCA / KL** | 对先验均方重建有效 | 大先验方差不等于大测量信息；小方差方向可能极关键 | 必须比较，但不默认采用 |
| **LIS / GN / sensitivity modes** | 明确区分数据相对先验的作用 | 局部性、分支、任务不确定性可能遗漏 | **核心诊断与分工工具** |
| **Characteristic modes** | 具有清晰的辐射、激励、共振物理意义 | 随对象和频率变化；不等于当前测量的统计可见性 | 物理解释层、候选预条件坐标 |
| **Scattering channels / \(S,T\)** | 外部多照明响应自然 | 内部任务及材料信息可能在压缩中丢失 | 响应任务优先的独立候选 |
| **Current / contrast source** | 与测量直接相连，便于物理残差 | 单照明依赖、共同材料一致性难保证 | 辅助状态，不默认唯一 canonical state |
| **Learned nonlinear latent** | 可能抓住低维非线性先验流形 | 梯度盲区、随机性删除、训练不可辨识、人工多模态 | 第二优先级，必须带审计 |
| **Hybrid** | 将坐标便利性、信息几何和条件随机补全分开 | 组件多，容易制造无法归因的实验 | **最值得做，但先用最简单组合** |

## 1. Wavelet 不只是“方便的 sparse basis”，但也不会创造信息

如果变换 \(W\) 完整且可逆：

\[
x=W\alpha,
\]

同时正确变换先验和度量，那么它并不改变原问题包含的信息，只是改变表示与计算方式。

真正产生差异的是：

- 截断哪些系数；
- 如何设计先验；
- 哪些系数由数据更新；
- 如何保留剩余随机性。

所以不应直接规定：

\[
\text{coarse}=\text{measured},
\qquad
\text{fine}=\text{prior}.
\]

在有限角度下，一些低频结构也可能缺失；在多次散射下，材料高频与测量的关系也不是简单的独立频率选择。

Born/Rytov 条件下的 Fourier diffraction 理论，确实能把照明、角度和频率与 Fourier coverage 联系起来；离开该近似后，应回到实际 tangent operator 检查。:chatgpt-content-reference{index="9"}

Haar 可以作为分块边界基线；Daubechies、biorthogonal 等可提供其他平滑性和局部性折衷。没有必要第一轮同时比较所有 wavelet。逆散射中 wavelet-subspace regularization，以及 wavelet 与 Bayesian compressive sensing 的组合，都已有直接先例。:chatgpt-content-reference{index="10"}

**推荐把 wavelet 当坐标，把 LIS 和任务不确定性谱当选择规则，而不是让 wavelet 层级自己决定物理重要性。**

## 2. Characteristic modes 和 LIS 不是二选一

Characteristic modes 主要刻画对象的电磁响应结构；LIS 则取决于：

\[
\text{对象}
+
\text{照明}
+
\text{接收阵列}
+
\text{噪声}
+
\text{先验}.
\]

它们回答的问题不同。

经典 characteristic-mode 与 \(T\)-matrix 的联系，已经有统一理论覆盖 PEC、可穿透结构及不同求解器表述。:chatgpt-content-reference{index="11"}

但不要说“有损系统的模式一定无法保持辐射功率正交”。2026 年已有 time-reversal characteristic modes，使用不同的反线性表述处理有损互易结构，并保留辐射功率正交性质。它并不等于传统有损特征分解没有问题，而是说明这里必须区分 modal definition。:chatgpt-content-reference{index="12"}

对你的算法而言，一个更合理的组合是：

\[
\boxed{
\text{固定物理通道或模式坐标}
\rightarrow
\text{实际测量与先验归一化}
\rightarrow
\text{LIS 与任务歧义分析}.
}
\]

而不是直接按照 modal significance 决定 posterior latent。

# 七、Multi-decode 应保留，但必须改成“同一样本的多种物理 readout”

## 1. 正确的样本生成图

我建议的新定义是：

\[
\boxed{
X^{(j)}\sim p(X\mid y),
}
\]

然后对**同一个** \(X^{(j)}\)：

\[
\boxed{
X^{(j)}
\longrightarrow
\left\{
J_s^{(j)},E_s^{(j)},H_s^{(j)},T^{(j)},y_{\rm new}^{(j)}
\right\}.
}
\]

因此，一个样本不是四个 head 的输出集合，而是：

> 一个物理对象 realization，以及这个对象在不同任务下的响应。

完整联合分布可写成

\[
p\!\left(dx,dq_1,\ldots,dq_K\mid y\right)
=
p(dx\mid y)
\prod_k\delta_{Q_k(x)}(dq_k).
\]

这直接保证输出位于共同的物理状态关系上。

但还要记住：

\[
\boxed{
\text{样本满足物理}
\neq
\text{样本具有正确后验概率}.
}
\]

一个偏置严重的采样器，也可以让每个输出都满足 Maxwell。

## 2. 哪些 readout 应该如何实现？

| Quantity | 优先实现方式 |
|---|---|
| 给定材料与照明的 \(J,E,H\) | **数值物理求解**；有可信 surrogate 后再加速 |
| 已知电流到接收响应 | 使用对应的线性观测算子 |
| 材料到多照明 \(S/T\) 响应 | 数值求解或受物理约束的响应算子 |
| 已知定义下的材料代数量 | 解析变换，不需要独立神经 head |
| 由截断 scattering state 推断材料 | 一般应保留 **probabilistic lift** |
| 等效电路、有效参数等非唯一描述 | 明确模型类别、约束和非唯一性，不能默认唯一 decoder |

尤其要核查 \(\rho\) 的定义。附件把它称为 reflectivity/scattering potential，但没有给出明确公式。若代码中它只是例如 \(k_0^2\chi\) 的确定性变换，那么它不是新的独立物理模态；若它是某种响应量，则需要对应的具体定义。:chatgpt-content-reference{index="13"}

## 3. 多 illumination 的关键要求：共同材料，而不是各自拟合

对于标量 current bank，给定预测的 \((J_s,E_s)\)，每个网格位置可检查是否存在共同材料：

\[
\widehat\chi_i
=
\frac{\sum_s E_{is}^\ast J_{is}}
{\sum_s|E_{is}|^2}.
\]

再计算

\[
\sum_s|J_{is}-\widehat\chi_iE_{is}|^2.
\]

若分母为零，该处材料不能由这些场状态识别；若残差不小，则 current bank 不对应共同的标量材料。

对于张量材料，需要相应照明场在方向上有足够激发，不能把这个标量公式直接套过去。

同时，对线性本构介质，应测试新照明的叠加关系：

\[
J(X,\alpha s_1+\beta s_2)
=
\alpha J(X,s_1)+\beta J(X,s_2).
\]

这比“新角度的场图看起来不错”更能检验它是否真的是 object representation。

# 八、非线性情况下，Flow 应该运行在哪种几何上？

## 1. 最准确的概念不是“固定 null space”，而是条件状态族

设存在一个低维统计量

\[
a=h(x),
\qquad
F(x)=f(h(x)).
\]

则精确后验分解为

\[
\boxed{
p(x\mid y)
=
\int p_0(x\mid a)\,p(a\mid y)\,da.
}
\]

这里：

- \(p(a\mid y)\)：数据和先验共同决定的 response-coordinate posterior；
- \(p_0(x\mid a)\)：在同一 response 下，材料仍可能怎样变化。

特别取 \(a=F(x)\) 时，这可以理解为：

\[
\boxed{
\text{先采样可能的无噪声响应}
\rightarrow
\text{再采样与它相容的物理对象}.
}
\]

**有噪声时，不应该把所有样本硬压到 \(F(x)=y\)。**

应该保留无噪声响应本身相对于观测的后验不确定性。

## 2. 沿纤维运动，只能保证约束，不能自动保证概率正确

在正则情况下，\(h:\mathbb R^d\to\mathbb R^r\) 满行秩。条件先验在纤维上的密度，相对于其表面测度，具有 coarea 因子：

\[
\boxed{
p_0(dx\mid h(x)=a)
\propto
\frac{p_0(x)}
{\sqrt{\det(J_hJ_h^\top)}}
\,d\mathcal H^{d-r}(x).
}
\]

所以：

\[
J_h(x)v(x)=0
\]

可以让连续轨迹保留 \(h(x)\)，但**并不能单凭这一点保证轨迹输运的是正确条件分布**。

任意生成后投影到物理流形，也不能自动等价于条件后验采样。2026 年已有专门研究 physics-constrained generation 中 coarea 测度修正及 flow distillation 的工作，因此这部分也不是未被研究的空白。:chatgpt-content-reference{index="14"}

但也不要错误地给所有 solver-based readout 都添加一个额外 determinant：

> 若先正确采样材料 \(X\)，然后确定性求解场，联合分布就是该材料后验的 pushforward；这不等于在独立生成的“材料—场环境空间”里再条件化到 PDE 残差为零。

两种概率构造必须分清。

## 3. 下一轮不必直接上最复杂的 Riemannian Flow

Riemannian Flow Matching 已经提供了在一般几何上构造生成流的方法。:chatgpt-content-reference{index="15"}

但对当前项目，更合理的顺序是：

**先证明选出的坐标保留了正确分布，再考虑路径是否需要 geodesic。**

一个可考虑的弱坐标度量是

\[
G_b
=
J_bD^\top
\left[
G_{\rm prior}
+
J_F^\top\Gamma_n^{-1}J_F
+
\sum_k w_kJ_{Q_k}^\top W_kJ_{Q_k}
\right]
J_bD.
\]

它体现先验、测量和任务尺度，但这是一个**设计候选**，不是唯一自然、自动最优的度量。

第一版更值得先做 posterior whitening、条件 source distribution 和简单路径。否则，encoder、metric、flow path 和 solver 同时变动，失败后仍然无法归因。

# 九、下一轮 latent shortlist：明确的 Top 3

## Top 1：可逆物理坐标／Wavelet + LIS + 条件随机补全

结构为：

\[
x=W\alpha,
\qquad
\alpha\leftrightarrow(z_s,z_w,z_n),
\]

其中 \(W\) 起初不做不可逆截断。

使用：

\[
p(z_s,z_w,z_n\mid y)
=
p(z_s,z_w\mid y)\,
p_0(z_n\mid z_s,z_w)
\]

作为精确理想形式；若 null 只是近似，则对应条件分布仍需要弱 likelihood 修正。

**为什么排第一：**它首先消除了“未知 encoder 到底丢了什么”的问题，使 representation、posterior transport 和物理 readout 可以分开验证。

**最可能成功的机制：**网络不再浪费容量重新学习强方向的尺度和简单高斯补全，把主要复杂度放在 weak directions 与非高斯条件相关性上。

**最可能失败的机制：**真正需要生成的条件先验仍然高维复杂；LIS 只减少了 likelihood-update 维数，并没有神奇消除所有生成难度。

最小实验阶段可以直接使用模拟器的真实物理生成参数，作为无 encoder 误差的 oracle 坐标。不能把使用测试对象真值计算的 LIS，当成可部署方法的性能。

## Top 2：保留测量切向的非线性 latent，加上显式随机残差

一种可审计的结构是，在白化材料坐标中：

\[
u
=
V_sa+(I-V_sV_s^\top)g_\theta(a,b,\xi).
\]

这样至少明确保留了 \(a=V_s^\top u\) 这组坐标，其他结构由 nonlinear decoder 与随机残差承担。

但这只保护了坐标本身；在非线性 full-wave 情况下，仍要检查实际的 \(J_FJ_D\)，不能声称一次构造就永久保护了测量敏感性。

训练目标不应只用材料 MSE，可以包括：

\[
L_{\rm meas}
=
\mathbb E
\left\|
\Gamma_n^{-1/2}
\bigl(F(X)-F(\widetilde X)\bigr)
\right\|^2,
\]

以及基于随机方向 \(r\) 的 tangent loss：

\[
L_{\rm tangent}
=
\mathbb E
\left\|
\Gamma_n^{-1/2}
J_F(X)
\bigl(I-J_DJ_e\bigr)C_0^{1/2}r
\right\|^2.
\]

再加上任务误差、先验分布与随机提升的检验。

**建议先把 representation 训练、审计、冻结，再训练 Flow。**之后才考虑 joint fine-tuning，并重新审计，避免 Flow 适应 encoder 的坏坐标后，看起来训练损失很好却无法解释。

潜在失败点包括 chart folding、模式分支混合、相位或排列造成的人工多模态，以及对训练 prior 的过拟合。

Latent 梯度看不见 decoder 切空间之外的测量残差，已有非常直接的 HDPS 近邻；其方法也已使用 full-space correction 加 latent alignment。因此，“发现 decoder Jacobian 盲区”不能再单独作为新贡献。:chatgpt-content-reference{index="16"}

## Top 3：固定通道的 scattering/operator latent + 条件材料提升

结构为：

\[
y\rightarrow p(T_{\rm fixed}\mid y)
\rightarrow p(X\mid T_{\rm fixed})
\rightarrow\text{物理 readouts}.
\]

优先使用固定的入射、出射通道，而不是每个样本都重新排序、定相位的对象特征模式。

**最可能成功：**最终任务主要是新照明响应、接收预测或外部散射行为，且算子具有稳定低秩结构。

**最可能失败：**需要的材料与内部场信息已经在 operator compression 中丢失；为恢复它们又增加一层复杂生成模型，整体反而比直接生成材料更难。

所以它值得保留，但目前不应抢占主线。

# 十、Flow Matching 值得保留，但它不是理论中心，也不是唯一合适的生成器

## 1. 值得保留的价值在哪里？

Flow Matching 的合理价值是：

\[
\boxed{
\text{摊销重复推断成本}
+
\text{表示复杂条件分布}
+
\text{快速生成多个联合样本}.
}
\]

不是“它恢复了测量里没有的信息”，也不是“它天然比 diffusion 更物理”。

Flow Matching 本身是一种训练连续输运模型的方法；rectified-flow 类路径和 continuous normalizing flows 与它存在紧密联系，不能把这些当作互不相干的类别。:chatgpt-content-reference{index="17"}

如果 null 条件先验就是一个可直接采样的 Gaussian，没有理由专门训练 Flow 去生成它。

反过来，如果 strong coordinates 存在全局分支，也没有理由禁止生成模型处理它们。

**“只生成 weak/null”应当是复杂度分配策略，而不是一条不允许例外的教条。**

## 2. Conditional source 比固定白噪声更值得优先考虑

可以使用：

\[
z_0=m(y)+L(y)\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I),
\]

其中 \(m(y)\)、\(L(y)\) 来自粗反演、局部后验或一个便宜的条件模型。

再用路径

\[
z_t=(1-t)z_0+tz_1
\]

训练条件速度场。

这样做的目的，是减少强弱方向之间不必要的尺度差异，而不是假设 source 已经等于后验。

对于多分支后验，可以使用混合 source 或 chart label。具有随机初值的确定性 ODE 完全可以表示多峰分布；真正需要额外小心的是精确低维支持、拓扑不连通支持与光滑可逆 flow 的兼容性。

## 3. 不能随意把 clean likelihood gradient 加进任意 Flow

常见的梯度

\[
J_D^\top J_F^\top\Gamma_n^{-1}(y-F(D(z)))
\]

描述的是当前物理状态的 likelihood 梯度。

但中间状态 \(z_t\) 的正确测量条件，一般涉及

\[
p_t(y\mid z_t)
=
\int p(y\mid z_1)p(z_1\mid z_t)\,dz_1.
\]

这通常不等于把 \(z_t\) 直接当作 clean endpoint 后计算的 likelihood。

因此，prior Flow 加 guidance 要么推导相应条件向量场，要么明确承认近似。已经直接学习 \(p(z\mid y)\) 的条件 Flow，再额外反复加 likelihood，也可能重复使用数据。

2026 年的 *Fast and Faithful* 已经研究将 operator-dependent data consistency 放入条件速度参数化，并端到端训练；“把物理 residual 放进 vector field”同样不是空白。:chatgpt-content-reference{index="18"}

## 4. 需要比较的 Bayesian baselines

| 方法 | 在你这里的主要角色 |
|---|---|
| MCMC、HMC、Langevin/MALA | 提供尽可能可信的后验参考；有限运行仍需收敛诊断 |
| Tempered SMC | 小模型中检查多峰、分支概率和 mode dropping |
| Laplace approximation | 判断后验是否真的复杂到需要生成模型 |
| Variational inference / normalizing flows / transport maps | 判断 FM 是否优于其他摊销后验表示 |
| Ensemble Kalman | 便宜的近似或优化基线，不能把 ensemble spread 自动解释为正确非高斯后验 |
| Randomized MAP / RTO | 连接优化与采样；非线性时需要注意样本分布修正 |
| Conditional diffusion | 与 FM 比较同一 latent、同一数据、同一物理 readout |
| Full-space conditional Flow | 排除“复杂 latent 系统还不如直接学”的可能性 |

低维输运与条件采样早已有成熟 measure-transport 框架；RTO 在线性高斯与非线性情况下的正确性也不同，非线性通常需要权重或接受—拒绝修正。:chatgpt-content-reference{index="19"}

同样，Ensemble Kalman 的高效率与其非线性、非高斯情形下的后验偏差，应分别评价。:chatgpt-content-reference{index="20"}

真正的计算比较应计入：

\[
C_{\rm train}
+
N_{\rm query}
\bigl(C_{\rm inference}+C_{\rm physical\ readout}\bigr),
\]

而不是只比较神经网络 NFE。

如果只有少量 inverse queries，或者每个 posterior sample 仍然要调用很多次昂贵 Maxwell solver，Flow 的摊销优势可能并不成立。

# 十一、下一轮的最小实验：先分辨错误机制，不要马上堆一个大工程

## 实验 A：一个解析 posterior benchmark，检验三种常见错误

本轮已经对以下小模型进行了核验。

### A1. 独立 heads 的条件均值错误

前面的两状态例子显示，即使每个 head 达到自己的最优均方误差，仍可能破坏

\[
J=\chi E.
\]

它检验的是 **joint realization**，与网络容量无关。

### A2. Null 分量的条件 prior 错误

前面的相关 Gaussian 例子显示：

\[
\operatorname{Var}(X_2\mid y)\approx0.1980,
\]

而独立 prior completion 给出 \(1\)。

它检验的是 **条件相关性**。

### A3. 固定 local null space 的非线性错误

考虑：

\[
Y=a+b^2+N,
\]

\[
a\sim\mathcal N(0,0.2^2),
\qquad
b\sim\mathcal N(0,1),
\qquad
N\sim\mathcal N(0,0.1^2),
\]

观测 \(y=1\)。

在原点：

\[
J_F(0,0)=(1,0),
\]

所以 \(b\) 是 local Jacobian 的 null direction。

但将 \(a\) 积分掉后：

\[
\boxed{
p(b\mid y=1)
\propto
\exp\left[
-\frac{b^2}{2}
-\frac{(1-b^2)^2}{2(0.2^2+0.1^2)}
\right].
}
\]

其两个模态位于约

\[
b=\pm0.9874.
\]

数值积分得到：

\[
P(|b|<0.5\mid y=1)\approx0.001374,
\]

而先验中：

\[
P(|b|<0.5)\approx0.382925.
\]

也就是说：

> **在原点被判为 null 的方向，经过有限幅度变化后，测量把其概率结构彻底改变了。**

如果先随便采样 \(b\)，再调节 \(a\) 保证 residual 很小，仍然可能得到完全错误的后验权重。

这些核验的可运行代码在这里：:chatgpt-content-reference{index="40"}，:chatgpt-content-reference{index="41"}。

## 实验 B：一个真正能筛选 latent 的小型 full-wave 实验

建议从小型 2D scalar Helmholtz 开始，但实验问题直接针对最终 Maxwell 机制：

**给定当前测量，能否正确表示那些会改变内部电流或新照明响应的材料不确定性？**

可以使用少量物理参数、小网格、两种训练照明，并保留第三种照明或一组接收条件作为未参与推断的任务。

关键是按以下顺序拆开。

### 第一层：先测试 representation，不训练 Flow

用真实材料样本或可信 posterior samples，直接检查各 latent 的：

\[
\text{材料重建误差},
\quad
\text{白化测量误差},
\quad
\text{tangent/secant 保真度},
\quad
\text{任务联合分布误差}.
\]

若已有真实 posterior samples 经过 encode/decode 就变坏，问题已经在 Flow 之前发生。

### 第二层：在相同 posterior reference 下比较采样器

至少比较：

\[
\text{raw coordinates},
\quad
\text{POD},
\quad
\text{wavelet/LIS hybrid},
\quad
\text{受保护的 nonlinear latent}.
\]

最初不必同时把 operator latent 的全部工程完成。

对极低维切片可以使用积分；对稍高维参数模型使用经过多链、分支和稳定性检查的参考采样。不能把一条没有诊断的 MCMC chain 当成真值。

### 第三层：寻找一对“测量相似、任务不同”的材料

在同一先验可行域中寻找 \(x_+\)、\(x_-\)，使

\[
\|\Gamma_n^{-1/2}(F(x_+)-F(x_-))\|
\]

很小，但

\[
\|Q(x_+)-Q(x_-)\|
\]

很大。

对于相同高斯噪声协方差，这两个对象的测量分布 KL 为

\[
D_{\rm KL}
=
\frac12
\|\Gamma_n^{-1/2}(F(x_+)-F(x_-))\|^2.
\]

这会形成一个非常有说服力的实验：

> 当前测量确实无法可靠区分这两个对象，但不同对象会产生不同的内部电流或新照明响应。你的 posterior 是否把这份歧义正确保留下来？

然后验证任务歧义特征问题能否比 POD、radiation significance 或单独 LIS 更准确地找到它们。

**这比“PSNR 提高了多少”更接近你要的理论论文。**

## 评价指标应同时覆盖三个层面

| 层面 | 检查内容 |
|---|---|
| 物理 realization | 本构关系、传播关系、共同材料、多照明叠加 |
| 概率分布 | mode probability、方差、联合相关性、coverage、energy score/CRPS |
| 任务能力 | 内部场、电流、新照明预测及其不确定性是否正确 |

Proper scoring rules 是为了评价整个概率预测，而不是只奖励 posterior mean。:chatgpt-content-reference{index="21"}

**一票否决项不是“重建均值不够漂亮”，而是：看似数据一致，却系统性删除真实模态或给出错误任务置信度。**

# 十二、数据、OOD、测量编码和未来扩展：哪些问题必须现在放进设计？

## 1. 数据集就是 prior，样本量没有一个通用数字

需要多少数据取决于先验复杂度、条件分布变化、罕见模式概率和 simulator 成本，而不只是 ambient dimension。

一个简单下界足以说明问题：某个先验分支概率为 \(1\%\)，要有 \(95\%\) 的概率至少见到一次，需要约

\[
N
\ge
\frac{\log 0.05}{\log 0.99}
\approx299
\]

个独立样本。

但“见到一次”远远不等于能学习正确的条件 mode probability。

因此不能用训练集总体规模掩盖条件分支样本不足。

公平比较不同 latent 时，还应保持同一个物理先验。不能在换 wavelet 坐标后顺便换成另一个更容易的先验，却把收益算成 representation 优势。

## 2. 存在 measurement-only OOD detection 的根本边界

设两个不同先验满足

\[
F_\#p_0^{(1)}=F_\#p_0^{(2)},
\]

即它们经过 forward map 后具有相同分布。

在相同噪声模型下，两者的 measurement distribution 完全相同，但纤维内部的材料与任务条件分布可以不同。

因此，任何只使用 \(y\) 的检测器，都无法可靠区分这类 prior shift。

这直接解释了附件中的现象：

\[
F(x)\approx y
\]

并不能验证不可观测结构的补全正确。:chatgpt-content-reference{index="22"}

latent density、ensemble disagreement、evidence 或其他诊断可以作为告警，但不能突破这个边界。真正能增加约束的是新照明、新频率、额外传感器或外部先验证据。

SBC 可以检查推断算法在**所假定 prior 与 simulator 下**是否校准，但不证明真实实验分布与 simulator 一致。:chatgpt-content-reference{index="23"}

## 3. Measurement encoder 可以用，但也要有 sufficiency 审计

在线性高斯模型

\[
y=Mx+n
\]

中，

\[
M^\top\Gamma_n^{-1}y
\]

可以作为与参数相关的充分统计量；其余仅影响与 \(x\) 无关的 likelihood 常数。

非线性情况下，随意压缩 measurement 就没有这个保证。

因此优先考虑物理 back-projection、已知通道变换，或经过 forward-family 审计的 learned encoder。Back-Projection Diffusion 已经把物理测量表示与生成式逆散射结合起来，不能把这一层单独作为新贡献。:chatgpt-content-reference{index="24"}

Dual latent 也不是天然新概念。2026 年 vsPAIR 就使用了 observation latent 与 quantity-of-interest latent 的配对结构。:chatgpt-content-reference{index="25"}

## 4. Nuisance parameters 应进入统计模型，而不是被 posterior “补成材料”

若存在 geometry、gain、phase 或 calibration uncertainty，应考虑

\[
p(x,\eta\mid y),
\]

而不是让 \(\chi\) 去吸收所有误差。

在线性化、独立 Gaussian nuisance prior 下，消去 nuisance 后的有效材料信息具有 Schur complement 形式：

\[
\boxed{
H_{\rm eff}
=
H_{xx}
-
H_{x\eta}
(H_{\eta\eta}+C_\eta^{-1})^{-1}
H_{\eta x}.
}
\]

所以 nuisance uncertainty 会改变 strong/weak/null 分类。

这与 self-calibration 研究有自然接口，但不意味着必须把两条论文合并。

## 5. Broadband、复杂材料与 symmetry 的处理原则

**频率。**单频 \(\chi\) 或 \(T\) snapshot 不能自动支撑 broadband response。若目标涉及色散、频谱或等效电路，应生成几何与受约束的本构参数，再得到 \(T(\omega)\)。逐频满足某个局部约束不等于整个频率响应满足 causality；Kramers–Kronig 等关系需要相应介质假设。:chatgpt-content-reference{index="26"}

**几何与材料。**可以分开 parameterization 和 prior，但不能因此宣称二者可以从给定测量独立识别。Factorization 是建模选择，不是 identifiability 证明。

**复数。**第一版采用 real/imag 表示最容易统一概率与噪声度量；amplitude/phase 要处理低幅值处相位不稳定和相位周期性。

**Gauge。**模式的排列、符号、相位与退化子空间旋转，可能制造人工多模态；优先比较子空间或投影算子，而不是未经对齐的单个 mode coefficient。但对象相对于固定阵列的平移、旋转一般是物理变化，不能随便 canonicalize 掉。

**多分辨率与自适应维数。**可以做分层生成，但每层由实际信息和任务指标审计，不要直接将尺度当作可见性。近简并特征值附近，平滑加权通常比硬阈值和逐模态跟踪更稳妥。

# 十三、N-Port、overlap 和 3D Maxwell：建议共享理论，不立即合并论文

附件提出将 overlap、current transfer、task tangent 重新纳入，这是有实质意义的，不需要为了“保持纯生成式”而排除。:chatgpt-content-reference{index="27"}

## 1. 最自然的共同接口，是后验几何所需的 tangent fidelity

设真实白化 tangent 是 \(A\)，N-Port 或其他 surrogate 得到 \(\widetilde A\)，且

\[
\|A-\widetilde A\|\le\varepsilon_A.
\]

在前面的线性 Gaussian 模型下，

\[
\Sigma=(I+A^\top A)^{-1},
\qquad
\widetilde\Sigma=(I+\widetilde A^\top\widetilde A)^{-1}.
\]

由逆矩阵恒等式可得：

\[
\boxed{
\|\Sigma-\widetilde\Sigma\|
\le
(2\|A\|+\varepsilon_A)\varepsilon_A.
}
\]

若任务 tangent \(B_Q\) 也被近似，还需计入它的误差，才能控制

\[
B_Q\Sigma B_Q^\top
\]

的偏差。

这个小推导说明：

> 对生成式后验而言，cheap forward 的价值不只是场图便宜，而是它是否保留了决定 likelihood update 和任务不确定性的方向。

这给 N-Port 一个非常自然、但非强制的角色：**可信 forward/tangent engine**。

至于它是否应该成为 latent，要看是否比直接物理参数或固定算子坐标更充分、更稳定、更便宜，不能由名字决定。

## 2. Overlap 应解释 conditioning，但不要直接等同于信息维数下降

参数化重叠可能使 \(J_D\) 病态；物理传播和测量则影响 \(J_F\)。最终进入推断的是

\[
J_FJ_D.
\]

因此要区分：

\[
\text{坐标冗余}
\quad\text{与}\quad
\text{真实物理不可辨识}.
\]

某个未经归一化的最小奇异值下降，也不自动意味着 data-informed dimension 下降；还需要考虑先验尺度、噪声和整个谱。

## 3. 3D vector Maxwell 的理论天花板在哪里？

上述结构并不依赖标量场本身。进入 3D 后，需要把：

- 标量材料乘法替换为相应本构块；
- 标量电流和场替换为向量场；
- tangent action 通过 forward/adjoint solves 实现；
- 非磁、各向同性等假设明确标出；
- 共振附近的条件数和 surrogate 误差单独控制。

核心链条仍然是：

\[
\boxed{
\text{constitutive perturbation}
\rightarrow
\text{current/field tangent}
\rightarrow
\text{acquisition filtering}
\rightarrow
\text{posterior uncertainty}
\rightarrow
\text{task readout}.
}
\]

真正有吸引力的理论成果，不是声称所有 Maxwell 后验都低维，而是：

> **给出某类可检验条件，预测哪些材料歧义会被当前测量隐藏，却在内部场或新照明任务中显著放大，并据此控制生成后验的随机自由度与 readout 误差。**

这条目标足够强，不需要先解决全局任意 Maxwell 逆问题才有价值。

# 最终建议：把论文问题改成“任务相关的全波后验坐标”，而不是“多头生成模型”

我建议将新的主问题明确写成：

> **在有限测量的全波逆散射中，哪些材料自由度主要承担 likelihood update，哪些自由度主要承担仍未消除的任务不确定性？如何以保留共同物理 realization 的方式，对后者进行条件生成？**

一个合适的工作标题可以是：

**Task-Relevant Posterior Coordinates for Full-Wave Inverse Scattering**

副标题强调：

**From Material-to-Current Transfer to Physics-Consistent Uncertainty Transport**

这条路线的核心不是 Flow Matching 的名字，而是下面这条链：

\[
\boxed{
\begin{gathered}
\text{材料—电流 tangent transfer}\\
\Downarrow\\
\text{测量信息谱与任务不确定性谱的失配}\\
\Downarrow\\
\text{保留必要随机自由度的 posterior representation}\\
\Downarrow\\
\text{同一个物理 realization 的多任务 readout}.
\end{gathered}
}
\]
